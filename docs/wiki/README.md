# NyanVim docs

NyanVim is a small, fast Neovim setup: IDE features, ~30 ms startup, a live theme switcher and an installer you can try next to your own config.

- [Installation](Installation.md) — try it, switch to it, update, uninstall
- [Keymaps](Keymaps.md) — every mapping, grouped the way which-key shows them
- [Customizing](Customizing.md) — your `lua/user/` overrides, adding plugins and languages
- [Theme](Theme.md) — Night City Mix, the four styles, matching your terminal
- [AI tools](AI-tools.md) — Claude Code, opencode and Ollama inside the editor
- [Troubleshooting](Troubleshooting.md) — what to check when something is off
- [Architecture](Architecture.md) — how the config is laid out and why

Website: https://nyanvim.vercel.app · Source: https://github.com/kyuna0312/NyanVim
